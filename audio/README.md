# Audio tracks

Add these MP3 files here for full music in the game:

- `paper-petals.mp3`
- `paper-moon-echo.mp3`
- `paper-moon-echo-ii.mp3`
- `paper-moon-echo-iii.mp3`

The list matches `js/preload-manifest.js`. Without them, the game still loads; rhythm may use fallbacks where available.

Netlify and local servers both serve files from this folder at `/audio/...`.
